1처음 시작하기

파일을 받고 매크로를 켜면 필요한 시트가 자동으로 만들어집니다. 처음 한 번만 하면 됩니다.

  1. 바차트_자동작성.xlsm 파일을 내려받습니다.
  2. 인터넷에서 받은 파일은 Windows가 매크로를 막습니다. 파일을 오른쪽 클릭 → 속성 → 아래쪽 「차단 해제」 체크 → 확인.
  3. 파일을 열고 화면 위 노란 줄의 [콘텐츠 사용]을 누릅니다.
    보안 경고 매크로를 사용할 수 없도록 설정했습니다. 콘텐츠 사용
  4. 초기 설정이 자동으로 실행되어 아래 시트들이 생깁니다. 자동으로 안 되면 시작 시트의 [초기 설정] 버튼을 누르세요.

저장할 때

반드시 Excel 매크로 사용 통합 문서(*.xlsm)로 저장하세요. xlsx로 저장하면 버튼이 동작하지 않습니다.

작업입력 내용으로 보고용 바차트를 만듭니다. 설정을 바꾼 뒤에도 이 버튼을 누르면 새 설정으로 다시 그려집니다. 작업입력의 간트 색도 함께 정리됩니다.

바차트의 세부작업 행을 숨겨 작업항목 줄에 바만 모아 보여줍니다. 요약 보고용.

숨긴 행을 모두 다시 보여줍니다.

대분류 줄만 남기고 숨깁니다. 대분류 줄에 아래 작업 바가 모여 있어 큰 흐름만 보고할 때 씁니다.

구역일정 시트로 이동합니다. 크레인 사용 같은 기간 일정을 입력할 때. 6장 참고.

예전 버전 파일의 작업입력·설정·공종·주요일정·공휴일을 이 파일로 옮겨옵니다. 8장 참고.

3작업입력

공정을 짜고 조정하는 작업 화면입니다. 왼쪽 표에 입력하면 오른쪽 간트가 바로 색칠되니, 흐름을 보면서 날짜와 기간을 맞추세요.

위쪽 버튼

메인의 [바차트 생성]과 같습니다. 조정이 끝나면 여기서 바로 누르세요.

간트 색, 들여쓰기, 날짜 머리글을 다시 맞춥니다. 색이 안 보이거나 공종을 바꾼 뒤 누르세요.

메인 시트로 이동합니다.

  • 구분은 목록에서 고릅니다. 세부작업은 바로 위 작업항목에, 작업항목은 바로 위 대분류에 속합니다. 순서가 곧 소속이라 빈칸을 남길 필요가 없습니다.
  • 공종도 목록에서 고르면 칸이 공종 색으로 바뀝니다. 비워 두면 위 단계 공종을 따라갑니다.
  • 작업내용은 바차트에서 선 위에, 하단표기는 선 아래에 씁니다. 「Anchor / Padding」처럼 두 줄로 나눠 쓸 때 하단표기를 쓰세요.
  • 노란 칸처럼 시작일과 기간만 넣으면 종료일(회색 칸)은 =시작일+기간-1 수식으로 계산됩니다.
  • 대분류의 날짜는 수식으로 자동 계산됩니다. 아래 작업항목·세부작업 중 가장 빠른 시작일 =MIN(…) ~ 가장 늦은 종료일 =MAX(…)이고(남색 글자), 간트에 전체 막대가 생깁니다.
  • 작업항목은 시작일을 직접 입력하면 입력한 그대로 씁니다(예: 노수리 기간 10/23 ~ 31일). 비워 두면 아래 세부작업 범위로 자동 계산됩니다. 다시 자동으로 돌리려면 작업항목의 시작일·기간을 지우세요.

간트 읽는 법

  • 막대 색 = 공종 색. 막대 가운데에 작업내용이 쓰이고, 막대가 짧으면 오른쪽에 씁니다.
  • 토요일은 파랑, 일요일·공휴일은 빨강이고 그날 칸은 연노랑입니다. 오늘 날짜는 노랑으로 표시됩니다.
  • 간트 날짜 범위는 메인의 차트 시작일 ~ 종료일을 따릅니다(바꾸면 바로 반영). 비우면 최초 작업이 있는 주의 월요일부터 400일입니다.
빨간 배경 행

종료일이 시작일보다 빠른 행입니다. 바차트에서 빠지니 날짜를 고쳐 주세요.

4공종

공종 이름과 색을 정하는 곳입니다. 여기서 정한 색이 작업입력 간트와 공종 칸, 그리고 공종색 바차트에 쓰입니다.

바꾼 공종 이름과 색을 작업입력 간트에 반영합니다. 색을 바꾼 뒤에는 꼭 누르세요. (이름을 고치면 자동으로 반영됩니다)

  1. 공종 추가: 빈 줄 A열에 이름(예: 도장)을 쓰고 B열 칸을 원하는 색으로 채웁니다.
  2. 색 바꾸기: B열 칸 선택 → 홈 → 채우기 색 → [색상 적용].
  3. 작업입력 공종 목록에 바로 나타납니다.
활용

조업 일정(정수, 노수리)을 「조업」 빨강으로 넣어 두면 공사 작업과 겹치는 구간이 한눈에 보입니다. 공종 이름을 바꿀 때는 작업입력에 이미 입력된 공종도 같이 고쳐 주세요.

5주요일정

SD 착수, 설비 반입, 시운전 같은 주요 이벤트를 바차트 날짜 아래에 ▼ 화살표로 표시합니다.

날짜 → 내용 → 색상을 물어보고 한 줄 추가합니다. 메인의 [주요 이벤트 추가]와 같습니다. 시트에 직접 입력해도 됩니다.

  • 색상: 빨강 / 파랑 / 초록 / 주황 / 검정 중에서 고릅니다. 예) 착수·완료는 빨강, 반입은 파랑.
  • 바차트에서는 ▼ + 날짜 + 내용으로 나오고, 글자가 겹치면 아랫단으로 내려갑니다. 두 단이 모두 차면 글자가 작아집니다.
  • 잠깐 숨기려면 메인의 주요 이벤트를 「숨김」으로 바꾸세요.

입력한 구역 일정을 바로 바차트에 반영합니다. (바차트 시트를 열어도 자동 반영)

출력하기

  1. 필요하면 세부작업을 접고, 메인에서 시작·종료·기간 열을 숨깁니다.
  2. Ctrl + P. A3 가로, 한 페이지 너비로 맞춰져 있고 인쇄 영역은 표까지만 잡혀 있습니다(안내 줄은 인쇄 안 됨).
  3. 여러 장이 되면 머리글(D-DAY ~ 구역 일정)과 왼쪽 구분 열이 매 장 반복됩니다.
알아 둘 점

바차트는 누를 때마다 작업입력 기준으로 다시 그려집니다. 바 영역에 직접 그린 선·글자는 지워지고, 바차트에서 고친 뒤에는 Ctrl+Z(실행 취소)가 되지 않습니다. 원본은 항상 작업입력입니다.

8새 버전으로 옮기기

새 버전 파일을 받으면 쓰던 내용을 버튼 하나로 옮길 수 있습니다.

  1. 쓰던 파일의 이름을 바꿉니다 (예: 바차트_이전.xlsm). 이름이 같은 두 파일은 엑셀에서 동시에 열 수 없습니다.
  2. 새 파일을 열고 [콘텐츠 사용] → 메인의 [이전 파일에서 가져오기] → 쓰던 파일을 선택합니다.
  3. 작업입력·메인 설정·공종·주요일정·구역일정·공휴일이 복사됩니다. 예전 3칸 양식(대분류/작업항목/세부작업)도 새 양식으로 자동 변환됩니다.
  4. [바차트 생성]을 누릅니다. 예전 양식에서 가져왔다면 공종 칸이 비어 있으니 골라 주세요.

9문제가 생기면

증상해결
빨간 줄 「이 파일의 원본을 신뢰할 수 없어 매크로를 차단했습니다」파일을 닫고 오른쪽 클릭 → 속성 → 「차단 해제」 체크 → 다시 열기.
버튼을 눌러도 아무 반응이 없음노란 줄의 [콘텐츠 사용]을 누르지 않은 상태입니다. 파일을 다시 열고 누르세요.
작업입력 간트에 색이 안 나옴작업입력의 [색상 다시 적용]을 누르세요. 공종이 공종 시트 목록에 있는지도 확인하세요.
작업입력을 고쳤는데 바차트가 그대로바차트 시트를 다시 열면 자동으로 다시 그려집니다. 안 되면 [바차트 생성]을 누르세요.
작업이 엉뚱한 작업항목 아래에 나옴작업입력에서 그 행의 위치를 확인하세요. 세부작업은 바로 위 작업항목에 속합니다.
바차트가 너무 길어 글자가 작게 인쇄됨메인의 표시 단위를 주·10일·월로 바꾸거나, 차트 시작일·종료일로 기간을 줄이세요.
구역 일정이 일부만 나옴구역은 처음 나온 순서대로 4개까지만 표시됩니다. 구역 이름을 합치거나 순서를 바꾸세요.
공휴일이 빨간색으로 안 나옴공휴일 시트에 날짜를 추가하세요. 2028년 이후는 직접 넣어야 합니다.
