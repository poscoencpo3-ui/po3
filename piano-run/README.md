## 무엇이 들어 있나

- **건반 판정**: 선에 닿을 때 누르면 PERFECT / GOOD / BAD / MISS. PERFECT·GOOD 이 이어지면 COMBO! 10콤보마다 관중이 응원해요.
- **긴 건반**: 별이 달린 긴 건반은 꾹 누르고 있다가 별이 선에 오면 손을 떼요.
- **달리기 경주**: 맞출수록, 콤보가 클수록 아래 캐릭터가 빨라져요. 혼자 할 때는 토끼 "깡총이", 강아지 "멍멍이"와 겨뤄요.
- **함께하기**: 4자리 방 번호로 들어오면 방장이 고른 곡을 동시에 연주하며 경주해요. 서로 달리는 모습이 보여요.
- **💬 대기실 채팅**: 경주 방에서 기다리는 동안 친구들과 말풍선으로 이야기해요. 글자를 못 써도 👋 안녕! · 준비됐어! · 😆 · 👍 같은 버튼을 누르면 바로 보내져요. 친구가 들어오고 나가면 알려 주고, 늦게 온 친구도 지난 이야기를 볼 수 있어요. 이야기는 어디에도 저장되지 않고 방을 나가면 사라져요.
- **음악**: 건반을 맞추면 멜로디가 화음과 함께 연주돼서, 누르는 대로 곡이 완성돼요. 피아노에 밴드의 리드 악기(바이올린·플루트·아코디언·트럼펫·오르골 등)가 같이 멜로디를 불러서 피아노만 따로 놀지 않아요. 조금 일찍 눌러도 소리는 반주 박자에 딱 맞춰 나와요. 반주는 곡마다 다른 밴드가 사람처럼 살짝씩 들쭉날쭉하게 연주하고, 두 번째 반복은 악기가 더해져 더 신나게! (모두 코드로 만든 소리, 공연장 울림 포함)
- **곡 14개** (모두 저작권이 끝난, 누구나 아는 곡) — 곡 이름 옆에 반주 스타일이 보여요

  | 단계 | 곡 | 반주 | 멜로디를 같이 부르는 악기 |
  |---|---|---|---|
  | 1 쉬움 | 작은 별 | 🎶 오르골 + 현악기 | 피아노 + 오르골 (한 옥타브 위) |
  | | 떴다 떴다 비행기 | 🪕 컨트리 (통통 베이스, 기타, 탬버린) | 피아노 + 바이올린(피들) |
  | | 나비야 · 런던 다리 | 🌸 봄 마림바 + 셰이커 + 박수 + 플루트 | 피아노 + 플루트 |
  | | 맥도날드 할아버지의 농장 | 🐮 밴조 붐칙 + 말발굽 우드블록 | 피아노 + 바이올린(피들) |
  | 2 보통 | 생일 축하합니다 · 위시 유 어 메리 크리스마스 | 🎉 파티 아코디언 쿵짝짝 + 탬버린 | 피아노 + 아코디언 |
  | | 환희의 송가 | 🎻 오케스트라 (팀파니, 금관, 심벌즈) | 피아노 + 바이올린 합주 |
  | | 징글벨 | 🛷 썰매방울 + 걸어가는 베이스 + 브러시 드럼 | 피아노 + 글로켄슈필 |
  | | 오 수재너 | 🪕 컨트리 | 피아노 + 바이올린(피들) |
  | 3 어려움 | 미뉴에트 G장조 | 🎼 하프시코드 + 첼로 | 피아노 + 하프시코드 |
  | | 엘리제를 위하여 | 🌙 피아노 (두 번째엔 잔잔한 비트) | 피아노 독주 |
  | | 터키 행진곡 · 양키 두들 | 🥁 행진 밴드 (큰북, 작은북 연타, 금관) | 피아노 + 트럼펫 |

## 내 컴퓨터에서 실행

```bash
cd piano-run
npm install
npm run dev
```

- **혼자 연주**와 **이 기기 랭킹**은 아무 설정 없이 동작합니다.
- 주소 끝에 `?local=1`을 붙이면 같은 브라우저의 탭끼리 경주를 해 볼 수 있습니다 (테스트용).

## 인터넷에 올리기 (슬라임 게임과 같은 방법)

1. **Supabase**: 슬라임 게임에서 쓰는 프로젝트의 SQL Editor에서 `supabase/piano.sql`을 한 번 Run
2. **Cloudflare Pages**: Workers 및 Pages → 만들기 → Pages → Git 연결 → `po3`
   - 프로덕션 분기: 게임이 있는 브랜치
   - 빌드 명령 `npm run build`, 출력 디렉터리 `dist`, 루트 디렉터리 **`piano-run`**
   - 환경 변수: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (슬라임 게임과 같은 값), `NODE_VERSION` = `22`

## 곡 추가하기

`src/songs.js`의 `SONGS`에 멜로디를 적으면 건반 악보가 자동으로 만들어집니다.

```js
melody: `C5:1 C5:1 G5:1 G5:1 | A5:1 A5:1 G5:2`, // 음이름옥타브:박자, R = 쉼표
chords: 'C C F C',                              // 반주 화음
arr: 'spring',                                   // 반주 스타일 (src/band.js)
```

멜로디가 올라가면 오른쪽 건반, 내려가면 왼쪽 건반으로 배치되고, 0.75초 이상 긴 음은 꾹 누르는 건반이 됩니다.

## 폴더 구성

```
piano-run/
├─ src/
│  ├─ main.js     화면 전환, 곡 고르기, 경주 방, 결과, 랭킹
│  ├─ game.js     연주 화면 (건반, 판정, 콤보, 달리기 경주)
│  ├─ songs.js    곡 악보와 건반 배치
│  ├─ music.js    피아노 소리·반주 진행·효과음
│  ├─ band.js     곡마다 다른 반주 밴드 (악기·편곡·멜로디 리드 악기)
│  ├─ scene.js    봄이 무대 / 별이 무대, 관중
│  ├─ chars.js    캐릭터
│  ├─ net.js      친구랑 경주 (Supabase Realtime)
│  ├─ chat.js     대기실 채팅 (같은 방 채널로 주고받음, 저장 안 함)
│  └─ rank.js     랭킹 저장
└─ supabase/piano.sql
```
