조작법

  • 캐릭터는 공을 따라 자동으로 움직입니다. 여러분은 타이밍만 맞추면 됩니다!
  • 공 주위의 줄어드는 원이 공에 딱 닿는 순간 클릭(또는 스페이스) — 바운드 후 공이 가장 높이 뜬 순간입니다
  • 마우스로 상대 코트의 노릴 곳을 가리키세요 (🎯 표시가 공이 떨어질 곳)
  • 왼쪽 클릭 = 드라이브(탑스핀, 빠르고 낮게) · 오른쪽 클릭 / Shift = 커트(백스핀, 느리고 뜸)
  • 클릭하는 순간 마우스를 좌우로 휘두르면 공이 휘어서, 위로 휘두르면 더 빠르게 날아갑니다
  • 타이밍이 좋으면 황금공, ±0.05초 안이면 🔥불꽃공!
  • 서브: 클릭으로 토스 → 원이 맞을 때 다시 클릭
