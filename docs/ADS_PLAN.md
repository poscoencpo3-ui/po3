# 광고(스폰서) 계획

게임을 방해하지 않으면서, 실제 경기장처럼 자연스럽게 광고가 보이게 하는 것이 목표입니다.

## 1. 광고 자리 (인벤토리)

| 자리 | 위치 | 노출 방식 | 상태 |
| --- | --- | --- | --- |
| **코트 광고판** | 코트를 둘러싼 LED 펜스 18면 (뒤 6면, 좌우 6면씩) | 8초마다 한 칸씩 돌아감 | ✅ 구현됨 |
| **전광판** | 천장에 매달린 점수판 | 30초마다 5초간 광고. 랠리 중에는 점수를 우선 표시 | ✅ 구현됨 |
| **대기실 배너** | 게임장 코드 아래 | 클릭하면 광고주 사이트로 이동 | ✅ 구현됨 |
| 탁구대·네트 로고 | 탁구대 옆면, 네트 | 고정 노출 (메인 스폰서) | 🔜 2단계 |
| 공·라켓 스킨 | 공 색/무늬, 라켓 고무 색 | 스폰서 테마 경기 | 🔜 3단계 |
| 마스코트 의상 | 핑퐁이 머리띠·깃발 | 고정 노출 | 🔜 2단계 |
| 결과 화면 | 매치 종료 배너 | "오늘의 경기 스폰서" | 🔜 2단계 |

## 2. 지금 바로 광고를 바꾸는 방법

`server/ads.json`을 고치면 됩니다. 서버를 다시 시작하지 않아도 몇 초 뒤에 반영됩니다. Render에서는 GitHub에 올리면 자동으로 다시 배포됩니다.

```json
{
  "id": "cafe-2026",
  "slots": ["board", "jumbotron", "lobby"],
  "title": "OO카페",
  "sub": "탁구 끝나고 시원한 음료 한 잔!",
  "bg": "#6f4e37",
  "fg": "#ffffff",
  "image": "/ads/cafe-logo.png",
  "url": "https://example.com",
  "weight": 3,
  "start": "2026-11-01",
  "end": "2026-12-31"
}
```

| 항목 | 설명 |
| --- | --- |
| `id` | 광고 구분 이름 (영문, 통계에 사용) |
| `slots` | 노출할 자리: `board`(광고판) / `jumbotron`(전광판) / `lobby`(대기실 배너) |
| `title`, `sub` | 큰 글씨 / 작은 글씨 |
| `bg`, `fg` | 배경색 / 글자색 (`#RRGGBB`) |
| `image` | 로고 이미지. `public/ads/` 폴더에 넣고 `/ads/파일명`으로 적거나, `https://` 주소를 씁니다 |
| `url` | 대기실 배너를 클릭하면 열릴 주소 |
| `weight` | 1~10. 클수록 더 자주 나옵니다 |
| `start`, `end` | 광고 기간 (선택) |

### 노출·클릭 통계
- Render의 Environment 메뉴에 `ADS_ADMIN_KEY`(관리자 비밀번호)를 설정합니다.
- `https://내주소/api/ads/stats?key=비밀번호`를 열면 광고별 노출 수와 클릭 수가 보입니다.
- ⚠️ 지금은 통계를 서버 메모리에만 저장합니다. **무료 서버가 잠들거나 다시 배포되면 통계가 0으로 초기화**됩니다. 영구 저장은 3단계에서 합니다.

## 3. 광고 원칙
1. **게임을 방해하지 않는다**: 팝업, 동영상, 소리 나는 광고는 넣지 않습니다. 전광판 광고는 랠리 중에 나오지 않습니다.
2. **광고임을 표시한다**: 전광판에는 `SPONSOR`, 대기실 배너에는 `광고` 표시를 붙입니다.
3. **허락받은 광고만 싣는다**: 실제 회사 로고와 이름은 광고주와 합의한 뒤에만 사용합니다. 상표권 문제가 생길 수 있기 때문입니다.
4. **함께 즐기는 게임에 맞는 광고만 받는다**: 도박, 성인, 주류 과다 광고는 받지 않습니다.

## 4. 단계별 계획

### 1단계: 하우스 광고 (현재)
- "이 자리에 광고하세요" 같은 자체 홍보 문구로 광고 자리를 미리 보여줍니다.
- 실제로 노출이 얼마나 되는지 통계로 확인합니다.

### 2단계: 직접 스폰서 받기 (지인·동호회·동네 가게)
- 탁구 동호회, 동네 탁구장, 스포츠용품점, 카페 등에 "경기장 광고판 한 면을 한 달 동안" 같은 방식으로 제안합니다.
- 메인 스폰서 자리(탁구대 로고, 마스코트 의상, 결과 화면)를 추가합니다.
- 소개 자료에는 1단계 통계(하루 경기 수, 광고 노출 수)를 활용합니다.

### 3단계: 광고 관리 페이지
- 관리자 화면에서 광고를 등록하고, 기간을 정하고, 이미지를 올립니다.
- 통계를 DB(예: Render PostgreSQL, Supabase)에 영구 저장하고 날짜별 그래프로 봅니다.
- 스폰서 테마 경기(공·라켓 스킨)와 시간대별 노출 기능을 넣습니다.

### 4단계: 광고 네트워크 연동 (규모가 커지면)
- Google AdSense 같은 네트워크 광고는 **게임 화면(캔버스) 안에는 넣지 않습니다**. 대기실과 결과 화면의 HTML 영역에만 넣습니다. 각 광고 네트워크의 정책도 지켜야 합니다.
- 보상형 광고를 검토합니다. 예: 광고를 보면 특별한 공 스킨을 줍니다.
- 이 단계에서는 개인정보 처리방침 페이지가 필요합니다.

## 5. 볼 지표
- **노출 수**: 자리별, 광고별
- **클릭 수와 클릭률(CTR)**: 대기실 배너
- **하루 경기 수, 동시 접속자 수**: 광고 단가를 정할 때 근거로 씁니다
- **경기 1판당 평균 광고 노출 시간**
