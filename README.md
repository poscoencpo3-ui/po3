# po3 — 새봄이·새별이 영어 교실

매일 두 아이(초2 새봄이, 6세 새별이)와 영어 공부를 하기 위한 **인쇄용 교재 자동 생성기**입니다.
브라우저에서 `index.html`을 열고 학생을 고른 뒤, 회차를 선택해 인쇄(또는 PDF 저장)하면
캐릭터 대화 형식의 컬러 A4 교재가 완성됩니다.

## 사용 방법
1. `index.html`을 브라우저로 엽니다 (더블클릭 또는 `open index.html`).
2. 상단에서 새봄이 / 새별이를 선택합니다.
3. "진도 현황"에서 다음 회차(▶ 표시)가 자동으로 열립니다. 다른 회차를 다시 보고 싶으면 목록에서 클릭하세요.
4. **인쇄 / PDF 저장** 버튼으로 교재를 인쇄하거나 PDF로 저장합니다.
5. 수업이 끝나면 **이 회차 완료 표시하기**를 눌러 다음 회차로 진도를 넘깁니다. (진도는 브라우저 localStorage에 저장됩니다.)

## 구성
- `index.html` — 생성기 메인 화면
- `css/style.css` — 화면/교재 스타일
- `css/print.css` — 인쇄(A4) 전용 스타일
- `js/curriculum-saebom.js` — 새봄이용 커리큘럼 데이터 (단어·문법·쓰기·회화)
- `js/curriculum-saebyul.js` — 새별이용 커리큘럼 데이터 (파닉스·단어·따라쓰기·듣기말하기)
- `js/characters.js` — 새봄이·새별이 캐릭터 SVG
- `js/app.js` — 진도 관리 및 교재 렌더링 로직

## 현재 상태 (MVP)
각 아이별 8회차(2일 1회 기준 약 16일 분량)가 들어 있습니다. 이후 회차는 같은 패턴으로
`js/curriculum-*.js`에 챕터 객체를 추가해 계속 이어갈 수 있습니다.

- 새봄이: Be동사 현재형 → 부정문 → 의문문 → 과거형 → 과거 부정문 → 종합 복습(일반동사 맛보기) 순으로 문법을 반복·확장하며 단어(가족/학교/감정/동물/날씨/음식/취미), 한 문장 쓰기, 대화문+롤플레이를 함께 다룹니다.
- 새별이: 파닉스를 Aa부터 알파벳 순서로 3자씩 진행하며(마지막 회차는 5자 복습), 단어 매칭·알파벳 따라쓰기·챈트+듣고 따라 말하기를 다룹니다. (파닉스 시작 지점은 기본값이며, 실제 진도에 맞게 조정 가능합니다.)
