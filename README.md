# 🏓 PING PONG ARENA

올림픽 경기장 분위기의 **멀티플레이 탁구 게임**입니다.
게임장을 만들면 5자리 코드가 생기고, 친구들이 그 코드를 입력해 같은 게임장으로 들어옵니다. **1:1 단식**과 **2:2 복식**(최대 4명)을 지원합니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
npm test           # 규칙/물리/봇 경기 시뮬레이션 테스트
```

1. 닉네임을 정하고 **사진을 올리면** 우스꽝스러운 큰머리 캐릭터가 만들어집니다.
2. **게임장 만들기**에서 단식/복식, 게임 수(1/3/5/7)를 고르면 코드가 나옵니다.
3. 친구는 **코드로 입장**에 코드를 입력합니다. `🔗 초대 링크 복사`로 `?room=코드` 링크를 보내도 됩니다.
4. 빈 자리는 방장이 **+ 봇**으로 채울 수 있습니다. 혼자 연습할 때도 쓸 수 있습니다.
5. 방장이 **경기 시작!**을 누릅니다.

> 친구들이 인터넷으로 접속하려면 WebSocket을 지원하는 Node 호스팅(Render, Railway, Fly.io, 개인 서버 등)에 배포해야 합니다. GitHub Pages 같은 정적 호스팅에서는 동작하지 않습니다.

## 조작법

| 동작 | 방법 |
| --- | --- |
| 서브 | 내 서브 차례에 클릭(또는 스페이스)하면 공을 토스하고, 공이 **떨어질 때 공을 클릭**합니다 |
| 리턴 | 공이 내 코트에 바운드되면 마우스로 따라가서 **공을 클릭**합니다 |
| 드라이브 | **왼쪽 클릭**: 탑스핀이 걸려 빠르고 낮게 깔리고, 바운드 후 앞으로 뻗습니다 |
| 커트 | **오른쪽 클릭** 또는 **Shift+클릭**: 백스핀이 걸려 느리게 뜨고, 바운드 후 멈칫합니다. 터치 화면에서는 `커트 모드` 버튼을 씁니다 |
| 파워 | 클릭하는 순간 마우스를 **앞(위)으로 휘두르면** 더 세고 깊게 들어갑니다 |
| 휘는 공 | 클릭하는 순간 마우스를 **좌우로 휘두르면** 사이드스핀이 걸려 공이 **휘어서** 들어갑니다 |

### 임팩트 타이밍 효과

공 중심에 가깝게, 바운드 후 정점(서브는 떨어지는 순간)에 맞힐수록 품질이 올라갑니다.
- **보통 타구**: 흰 잔상
- **GREAT** (품질 62% 이상): 공이 **노란 황금공**으로 바뀌고 반짝이는 잔상이 남으며 속도가 빨라집니다
- **PERFECT** (품질 82% 이상): **🔥 불꽃공**이 됩니다. 불꽃 파티클, 화면 흔들림, 관중 환호가 나오고 가장 빠르고 날카롭게 꽂힙니다
- 타이밍이 나쁘면 공이 아웃되거나 네트에 걸릴 수 있습니다

## 탁구 규칙 (ITTF 기준)

- 한 게임은 **11점**이고, 10:10(듀스) 이후에는 **2점 차**가 나야 이깁니다
- 매치는 1게임, 3게임 중 2선승, 5게임 중 3선승, 7게임 중 4선승 중에서 고릅니다
- 서브권은 **2점마다** 교대하고, 듀스 이후에는 **1점마다** 교대합니다
- 서브는 자기 코트에 한 번, 상대 코트에 한 번 바운드해야 합니다. 네트에 맞고 들어간 서브는 **렛**(다시 서브)입니다
- 토스한 공을 치지 못하면 서브 실패입니다
- 복식 서브는 **오른쪽 하프에서 상대 오른쪽 하프로 대각선**으로 넣어야 합니다
- 복식은 **번갈아 치기**입니다. 서버 → 리시버 → 서버 파트너 → 리시버 파트너 순서이고, 화면에 다음 차례가 표시됩니다
- 복식 서브 순서는 (A1→B1) → (B1→A2) → (A2→B2) → (B2→A1)로 돕니다
- 다음 게임은 직전 게임의 첫 리시버가 서브합니다
- 리턴한 공이 상대 코트에 바운드하지 않으면 실점, 내 코트에 두 번 바운드하면 실점입니다

단순화한 부분도 있습니다. 엔드 교체는 화면상 의미가 없어서 생략했습니다. 마지막 게임에서 5점이 났을 때 복식 리시브 순서를 바꾸는 규칙과 촉진 규칙도 적용하지 않았습니다.

## 캐릭터 생성 (Higgsfield)

사진을 올리면 다음 순서로 처리됩니다.

1. **바로** 브라우저 안에서 임시 캐리커처를 만듭니다. 볼록 렌즈 왜곡으로 큰 눈과 큰 얼굴을 만들고, 만화풍 색감과 볼터치를 더합니다. 바로 게임을 시작할 수 있습니다.
2. 서버에 Higgsfield 키가 설정되어 있으면 서버가 **Higgsfield API**로 캐리커처를 요청합니다.
   - `POST /files/generate-upload-url`로 업로드 URL을 받아 사진을 PUT 업로드합니다
   - `POST /{모델}`에 프롬프트와 이미지 URL을 보내 생성을 요청합니다
   - `GET /requests/{id}/status`를 완료될 때까지 폴링합니다
   - 결과 이미지는 서버가 내려받아 전달합니다
3. 완료되면 아바타가 **자동으로 교체**됩니다. 대기실에 있든 경기 중이든 같은 방의 모든 플레이어 화면에 바로 반영됩니다.

설정은 `.env.example`을 `.env`로 복사해서 키를 넣으면 됩니다. 키는 서버에만 있고 브라우저로 전달되지 않습니다.

```bash
HIGGSFIELD_API_KEY=발급받은_키
HIGGSFIELD_API_SECRET=발급받은_시크릿
# 또는 HF_KEY=키:시크릿

# 계정에서 쓸 수 있는 이미지 편집 모델에 맞게 바꿀 수 있습니다
HIGGSFIELD_MODEL=bytedance/seedream/v4/edit
HIGGSFIELD_IMAGE_FIELD=image_urls
```

키가 없거나 생성에 실패하면 브라우저 캐리커처를 그대로 씁니다.

## 구조

```
server/index.js      Express + Socket.IO 서버, 게임장(코드) 관리, /api/caricature
server/room.js       게임장: 슬롯(A1,A2,B1,B2), 서버 권위 물리 루프(60Hz), 판정, 봇 AI
server/rules.js      탁구 규칙 순수 함수 (서브 순서, 타구 순서, 게임/매치 승리)
server/higgsfield.js Higgsfield API 연동
shared/physics.js    서버/클라이언트 공용 공 물리 (드라이브/커트/사이드스핀, 바운드, 네트)
public/js/arena.js   올림픽 경기장 렌더러 (관중, 광고판, 탁구대, 선수, 공 효과)
public/js/game.js    UI, 입력(마우스 추적·스윙 측정·타이밍 판정), 네트워크 동기화
public/js/caricature.js  사진 → 캐리커처 (Higgsfield / 브라우저 대체)
public/js/audio.js   WebAudio 효과음 (타구, 바운드, 관중 환호)
```

공은 "스핀 = 일정한 가속도" 모델로 움직입니다. 그래서 타구 순간 목표 지점에 정확히 떨어지는 초기 속도를 계산할 수 있고, 휘는 공도 의도한 곳에 들어갑니다. 서버가 판정을 맡고, 클라이언트는 같은 물리로 30Hz 상태 사이를 예측해 부드럽게 그립니다.
