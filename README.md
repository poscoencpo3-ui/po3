# po3 — 새봄이·새별이 영어 교실

매일 두 아이(초2 새봄이, 6세 새별이)와 영어 공부를 하기 위한 **인쇄용 교재 자동 생성기**입니다.
브라우저에서 `index.html`을 열고 학생을 고른 뒤, 회차를 선택해 인쇄(또는 PDF 저장)하면
캐릭터 대화 형식의 컬러 A4 교재가 완성됩니다.

## 사용 방법
1. `index.html`을 브라우저로 엽니다 (더블클릭 또는 `open index.html`).
2. 상단에서 새봄이 / 새별이를 선택합니다.
3. "진도 현황"에서 다음 회차(▶ 표시)가 자동으로 열립니다. 다른 회차를 다시 보고 싶으면 목록에서 클릭하세요.
4. **인쇄 / PDF 저장** 버튼으로 교재를 인쇄하거나 PDF로 저장합니다.
5. 수업이 끝나면 **이 회차 완료 표시하기**를 눌러 다음 회차로 진도를 넘깁니다. (진도는 브라우저 localStorage에 저장됩니다.)

## 구성
- `index.html` — 생성기 메인 화면
- `css/style.css` — 화면/교재 스타일
- `css/print.css` — 인쇄(A4) 전용 스타일
- `js/curriculum-saebom.js` — 새봄이용 커리큘럼 데이터 (단어·문법·쓰기·회화)
- `js/curriculum-saebyul.js` — 새별이용 커리큘럼 데이터 (파닉스·단어·따라쓰기·듣기말하기)
- `js/characters.js` — 새봄이·새별이 캐릭터 SVG
- `js/app.js` — 진도 관리 및 교재 렌더링 로직

## 현재 상태
- **새봄이(초2)**: 총 42회차(2일 1회 기준 약 84일) — 학습 회차 35개 + Review Test 7개(5회마다 1개)로
  초등 기초 문법 한 사이클 + 심화(전치사·어순·빈도부사·명사/관사)까지 완주 + 정기 복습하도록 구성했습니다.
  1~5회 Be동사 현재형(+6회 Review) → 7~11회 Be동사 과거형·일반동사 맛보기(+12회 Review) →
  13~17회 일반동사 현재·과거형(+18회 Review) → 19~23회 일반동사 과거·현재진행형·There is/are(+24회 Review) →
  25~29회 There is/are 부정의문·지시대명사·소유격(+30회 Review) → 31~35회 조동사 can·의문사·총정리(+36회 Review) →
  37~41회 전치사(장소·시간)·문장 기본 어순(SVO)·빈도부사 위치·명사 복수형+관사(+42회 최종 Review).
  각 학습 회차 문법 섹션에는 설명 3줄 + 주의사항(tip) + 표 + 예문 + 빈칸연습 + **객관식 2문제 + 어순배열/문장전환 2문제**가
  들어있고, 단어 8~10개, 쓰기(문장완성 3+단어로 문장만들기 3+자유작문), 대화문+롤플레이가 함께 제공됩니다.
  Review Test 회차는 직전 5회 분량을 객관식 10문제 + 문장전환/어순배열 5문제 + 서술형으로 총정리합니다.
  모든 정답은 문제 옆에 노출하지 않고, 회차 맨 끝의 "정답" 박스에 180도 회전(거꾸로)해서 모아 표시합니다.
  (e-future My First Grammar의 나선형 반복 구조, NE능률 Grammar Inside의 다양한 문제유형+Review Test+명사/관사 구성을 참고했습니다.)
- **새별이(6세)**: 총 8회차, 파닉스를 Aa부터 알파벳 순서로 3자씩 진행하며(마지막 회차는 5자 복습),
  단어 매칭·알파벳 따라쓰기·챈트+듣고 따라 말하기를 다룹니다. (파닉스 시작 지점은 기본값이며, 실제 진도에 맞게 조정 가능합니다.)

이후 내용은 같은 패턴으로 `js/curriculum-*.js`에 챕터 객체를 추가해 계속 이어갈 수 있습니다.
